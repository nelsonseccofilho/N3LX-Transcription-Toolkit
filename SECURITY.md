# Security and privacy

This repository aims to help people transcribe **their own or authorized** media locally. Local processing does not remove responsibilities around consent, privacy, model terms and retention.

## Do not publish

- API keys, Hugging Face tokens, passwords, session secrets or OAuth credentials.
- Real client recordings, private meeting videos or unapproved transcripts.
- Environment-specific home directories, user names, IP addresses or machine identifiers.
- Unredacted terminal captures or screenshots containing sensitive information.
- Proprietary dependencies or third-party model weights without redistribution rights.

Use environment variables or supported secure local credential storage. Keep local outputs and temporary audio outside Git.

## Reporting vulnerabilities

Do **not** put exploitable security details or credentials in a public issue. Prefer the repository's private vulnerability reporting feature if available. Otherwise contact the repository owner privately through an established channel before public disclosure.

## Dependencies and third-party models

Review upstream licenses, redistribution rights, download sources and model access terms before adding automation or packaging installers. Document versions and hashes of downloaded artifacts when possible.
